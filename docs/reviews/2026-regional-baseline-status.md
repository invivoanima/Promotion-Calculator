# 2026년 지역별 계산 모듈 적용 현황

작성일: 2026-10-19. 평정 기준일: 2026-02-28.

## 구현과 검증 범위

17개 지역을 각각 독립된 계산 제공자로 등록했다. 전남 외 16개 지역에는 선택가산점을 제외한 9개 항목의 입력·수정·삭제·기록별 계산·항목 합산·카테고리 합산·총점을 구현했다. 회원 저장과 비회원 브라우저 저장에서 같은 지역 모듈을 사용한다.

**16개 교육청의 2026년 초등 원문을 모두 확보·대조한 결과는 아니다.** 국가 법령의 기본 계산을 각 지역 파일에 독립적으로 구현한 상태다. 교육청 고유의 연수 학점 상한, 과정 인정, 경과조치, 자격연수 대상자 선발 기준은 미확인이다. 이 상태는 지역 선택 화면과 계산 페이지·자료 화면에 표시한다. 기능 테스트 통과를 규정 검증 완료로 해석하지 않는다.

| 지역 | 경력·근무·연수·공통 9개 입력 | 선택가산점 | 교육청 원문 대조 |
|---|---|---|---|
| 서울·부산·대구·인천·광주·대전·울산·세종 | 기본 계산 구현 | 제외 | 미완료 |
| 경기·강원·충북·충남·전북·경북·경남·제주 | 기본 계산 구현 | 제외 | 미완료 |
| 전남 | 기존 지역 모듈 유지 | 기존 구현 유지 | 포함 PDF 감사 완료, 발견된 차이 후속 수정 필요 |

## 새 16개 모듈의 명시적 기본값

| 항목 | 기본 구현 |
|---|---|
| 경력 | 기본 15년 최대 64점 + 초과 5년 최대 6점. 입력한 인정기간·등급으로 산정, 만기 등급별 만점 및 최종 소수 셋째 자리 반올림 |
| 근무성적 | 2021~2025학년도 중 최종 34/33/33 가중합이 가장 높은 3개 학년도. 동일 학년도는 최고점 1건, 최종 소수 셋째 자리 반올림 |
| 자격연수 | **교감 승진 명부**의 교감 자격연수 성적에 `9 − (100 − 성적) × 0.05`. 60~80점 미만은 80점 적용, 60점 미만 미평정 |
| 직무연수 | 2016.3.1.~2026.2.28. 수료한 60시간 이상·성적 60점 이상 과정. 성적용 1개 환산점 + 그 밖의 이수용 최대 2개 각 6점 |
| 연구실적 | 입력한 인정점수 기준 연구대회 학년도별 최고 1개 + 학위 최고 1개, 합계 최대 3점 |
| 교육부 연구학교 | 월 0.018·일 0.0006, 최대 1점 |
| 재외국민교육기관 | 월 0.015·일 0.0005, 최대 0.5점 |
| 연수 학점 | 학점당 0.02, **학년도별 0.12·총 1점의 법령 한도**를 임시 기본값으로 사용 |
| 학교폭력 실적 | 인정 학년도당 0.1, 같은 학년도 중복 제외, 최대 1점 |

경력 인정 기간·휴직 비율·겹치는 기간, 연수의 동일·유사 과정 및 기관 인정, 연구대회 인정 점수는 확인한 실적을 사용자가 입력한다. 국가 법령의 기본 계산이 모든 개인별 특례를 자동 판정한다는 의미는 아니다. 연구실적 학위 중복 인정의 과거 특례도 지역 원문 확인 후 해당 파일에서 보완해야 한다.

전남은 현재 자격연수 대상자 선발 계수 0.025와 직무연수 인정기간 2016.1.1.부터의 기존 규칙을 보존한다. 새 지역의 교감 승진 명부 기본 계산과 평정 대상을 혼동하지 않도록 설명을 표시했다. 전남 자체 미반영 조건은 [기존 PDF 감사](2026-manual-calculation-audit.md)에 있다.

평정 대상이 다른 자격연수 원입력이 섞이지 않도록 새 16개 지역의 자격연수는 지역 포트폴리오별로 저장한다. 기존 전남의 1급 정교사 자격연수 성적을 교감 자격연수 성적으로 자동 재사용하지 않는다.

## 근거와 미확인 값

기본 계산의 출처는 [교육공무원 승진규정, 시행 2023.6.13.](https://law.go.kr/LSW/lsPdfPrint.do?ancYnChk=0&bylChaChk=N&efGubun=Y&efYd=20230613&joAllCheck=Y&joEfOutPutYn=on&lsiSeq=251543&mokChaChk=N)의 경력·연수·명부 작성·공통가산점 조항이다. 2026.2.28. 평정에 뒤의 2026.6.16. 개정을 소급 적용하지 않는다.

연수 학점의 법령 한도는 교육청 확정 상한과 다를 수 있다. 예를 들어 전남 포함 PDF는 연 0.08·총 0.8을 사용한다. 다른 교육청에 그 숫자를 대입하지 않았다. 검색으로 확인한 경기 자료 등 일부 자료가 있더라도 2026년 초등 기준을 전체 대조하지 않은 상태에서 검증 완료로 표시하지 않았다.

교육청 원문을 확보하면 해당 지역의 `policy.py`, `catalog.py`, 카테고리 계산·검증·최종 합산을 고치고, 출처·시행일·경과조치 및 기준 사례를 기록해야 한다. 다른 지역 모듈 수정은 필요하지 않다.

## 검증

`calc/test_all_regions.py`는 새 16개 지역의 9개 항목별 입력·계산, 회원 저장·수정·삭제, 비회원 저장·재계산·수정·삭제, 상한·학년도 중복·연수 분리·가중합·경력 만점과 다른 지역 변경의 영향 차단을 검증한다. 테스트 입력은 가상의 실적이며 실제 회원 DB를 변경하지 않는다.

전체 Django 테스트 73개 통과 후 근무성적의 최종 소수 셋째 자리 반올림을 추가 점검했다. 최종 변경은 새 16개 지역의 계산 테스트 11개로 재검증하여 통과했다. Django 시스템 검사와 마이그레이션 변경 검사도 통과했으며 기존 DB 스키마 변경은 없다.
