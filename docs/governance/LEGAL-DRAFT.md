# 이용약관·개인정보처리방침 내부 초안

작성일 2026-09-09. **게시 불가·검토 전용. 시행일 아님.** 운영자·연락처·기간·위탁·국외 이전·연령·법적 근거가 미확정이며 아래 문안으로 현재 법적 적합성을 주장하지 않는다. 완성된 공개 문서처럼 연결하지 않는다. 조항별 현행 대비 변경표는 PROJECT-ADOPTION.md 3절의 TERMS/PRIV 전 항목이다.

## 법령 확인 기록과 한계

확인일 2026-09-09. 공식 페이지의 열람 결과와 확인되지 않은 사실을 구분한다.

- [개인정보 보호법 제30조](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1020398435): 페이지는 시행 2025-10-02, 법률 제20897호로 표시했다. 목적·기간·파기·권리 행사·책임자 등 방침 항목과 공개 의무를 확인했다. 이 프로젝트의 개별 처리 근거·보존기간까지 확정하는 조문은 아니다.
- [개인정보의 안전성 확보조치 기준](https://law.go.kr/admRulLsInfoP.do?admRulSeq=2100000281400): 시행 2026-07-01, 고시 제2026-9호 표시 확인. 도구 열람에서는 본문·부칙 전문이 반환되지 않아 조문별 유예·적용대상·정확한 기간은 확정하지 못했다. **법령 전체 및 경과조치 최신성 확인은 미완료**다. 운영자 분류와 정보주체 규모를 확인하고 원문·부칙을 재검토해야 한다. 다른 프로젝트의 조회기록 제외를 면제 근거로 삼지 않는다.
- [통신비밀보호법 시행령 제41조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=121362): 시행 2025-08-01 표기와 전기통신사업자 관련 조문임을 확인했다. 검색 결과에 일부 통신사실확인자료 3개월 규정이 있으나 이 프로젝트가 해당 사업자인지, 어떤 로그가 해당 자료인지 미확정이다. 이를 모든 행동로그의 법정 보유기간으로 전용하지 않는다.

확정 작업: 실제 적용 법역·사업자/처리자 분류 → 목적별 최소 항목·처리 근거 → 로그 종류별 법정 의무/운영상 필요 → 기간·기산점·파기 → 공개문안 순서로 검토한다. 아직 확인하지 못한 법적 의무를 충족했다고 보고하지 않는다.
